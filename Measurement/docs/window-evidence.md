# 两端点扩窗证据判定（2026-10-26）

核心调用 `measure_frame(frame, detections, intrinsics, config)` 保持兼容。两个端点独立执行，最大窗口边长仍不超过检测框短边。最终 Z 始终由选定目标样本的算术均值产生，再沿原关键点射线计算 XYZ；诊断平面不提供输出深度。

## 端点深度模式

默认 `endpoint_depth_mode="near_cluster_mean"`（近簇均值近似）：关键点可以落在背景上，在当前搜索窗内关联具有框内连线带支持的近簇。保持原始 `(u,v)`，用选中目标的算术均值作为该射线的近似 Z。平面代表性和新增区域均值差仅提示，不阻断；两簇分离、样本量、归属明确性、内部双群、跨窗稳定性、新增样本和空间覆盖仍为硬条件。

可选 `"strict_local"`（严格局部一致）：固定 3/5 px 锚区，并要求平面代表性及新增区域均值差通过。主界面右上角切换，切换后清除旧结果、重新计算；加载和保存配置包含该模式。旧配置未声明模式时使用默认近似模式。

近似深度不能纠正原始二维位置误差；XYZ 是原射线上的估计点。即使附近真实表面有坡度，也保留其算术均值并提示可能的偏差，不把拟合深度替换为输出。

## 新增判定

1. **端点锚区**：在原关键点周围依次检查半径 3、5 px。近似模式支持不足时，扩展到当前窗内最近的足够样本，不采集窗外像素；严格模式保留固定锚区。目标分量须在框内连线带中提供至少 6 个锚区样本；先按锚区半径和支持量关联目标，再考虑整体支持量。多个深度不同且锚区支持相当的分量拒绝。自定义六参数 selector 仍可调用，返回样本也必须通过独立锚区检查。
2. **目标内部双群**：对选中分量再做 Otsu/MAD 子群检查。两个子群各至少占目标样本 20%、各至少 12 点，中心差至少 20 mm、分离度至少 2、远 P10 与近 P90 间隔至少 5 mm 时，拒绝混合取均值。
3. **均值代表性**：对目标样本以归一化像素坐标拟合稳健局部平面，用四轮以内 MAD 修剪核验局部模型。至少 12 点、至少 60% 内点、设计矩阵秩为 3、条件数不超过 10000。原点拟合 Z 与算术均值的偏差加两倍形式标准误裕量参考阈值为 5 mm；默认仅提示模型不可靠或偏差过大，严格模式要求通过。这里的形式标准误仅检查模型稳定性，不能将空间相关像素视为独立样本，更不是正确概率区间。拟合剔除只用于诊断，最终样本均值不被替换。
4. **新增证据**：只统计前一窗口 `valid_ids` 尚未包含的像素。旧像素重新分类不会被当作新增样本。新增目标和远簇分别须不少于 `max(12, ceil(上一窗对应数量 × 0.10))`，否则连续通过计数归零。新增目标均值与本窗保留目标均值之差参考阈值为 5 mm；默认仅提示超限或缺少可比较样本，严格模式要求通过。首窗仍不能通过稳定性比较；裁剪后未增长的窗口继续去重。
5. **空间覆盖**：按原图 2×2 px 网格计数，近、远和选中目标各至少覆盖 12 格。格数表示空间覆盖，不代表独立样本数量。默认样本门槛较大时，12 格可能自然满足；实际数据可调整格尺寸及最低格数，不能据此宣称消除了配准复制或邻近像素相关性。

原分离度、分位间隔、样本量、共有像素 Jaccard、中心稳定性与四项最小评分继续计算。所有硬条件均满足才能累积连续通过；高评分不能覆盖新增证据的失败。窗口达到上限仍未通过时拒绝，不退回一个高评分但未完成连续验证的结果。

## 可配置参数

| 参数 | 默认值 |
|---|---|
| `endpoint_depth_mode` | `near_cluster_mean` |
| `anchor_radii` / `anchor_min_samples` | `[3,5]` / `6` |
| `subgroup_min_fraction` / `subgroup_min_samples` | `0.20` / `12` |
| `subgroup_center_gap_m` / `subgroup_separation_min` / `subgroup_gap_min_m` | `0.020` / `2.0` / `0.005` |
| `plane_min_samples` / `plane_min_inlier_fraction` / `plane_max_condition` | `12` / `0.60` / `10000` |
| `plane_bias_max_m` | `0.005` |
| `growth_min_samples` / `growth_min_fraction` / `growth_mean_max_m` | `12` / `0.10` / `0.005` |
| `coverage_cell_px` / `coverage_min_cells` | `2` / `12` |

旧配置缺少这些键时使用上述默认值。界面“参数设置”可修改，重新计算生效。它们是模拟阶段初值，不能代替真实 RGB-D 标定。

## 诊断与重现

每窗 JSON 增加 `anchor`、`subgroups`、`plane`、`growth`、`coverage`、`consecutive_passes`、`advisories` 及 `warnings`。`checks` 只包含硬条件；提示项单独记录。判定页逐项展示真实检查结果，失败行着色并滚动定位；“提示（不阻断）”明确区别于“未通过”，判定记录保留警告、新增数量、梯度偏差和覆盖摘要。

模拟场景包括“端点斜面（均值偏离端点）”和“相接双表面（混合均值）”。斜面样例没有运行 YOLO，其输入点实际在目标上，11 mm 偏差来自梯度与邻域均值；默认近似模式允许输出且保留偏差提示，严格模式拒绝。相接双表面在两种模式下仍由内部双群检查拒绝混合平均。

当前验收报告：`outputs/near_mean_zoom_validation/benchmark.json`，同时记录斜面两种模式的结果及实际偏差。新增测试见 `tests/test_near_mean_zoom.py`：落在背景的原像素经扩窗恢复近簇均值、原射线不变、模式切换清空结果、提示项显示，以及旋转和平移后的滚轮锚定。滚轮按光标位置缩放，支持小幅触控板输入；零垂直增量不改变视图，达到缩放上下限不继续漂移。

本轮 48 项单元测试通过。相接双表面按 20 个固定种子全部拒绝；正常场景通过率单独统计，避免以全部拒绝获得低误差。

目前缺少真实相机深度数据。错误关键点、稳定的背景回波、折射伪深度等仍可能产生不可辨识情况；这些检查不能恢复不存在的真实观测。

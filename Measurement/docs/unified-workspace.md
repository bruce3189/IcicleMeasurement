# 统一工作窗口与端点欧氏距离

主窗口顶部现在只有“场景生成”“测距分析”两个工作页。原 `--pseudo-depth` 启动参数与桌面快捷方式继续有效，切换到生成页，不另开生成弹窗。模型组件按需导入。

生成或加载项目、应用修正、切换送测深度版本后，工作台使用当前测距配置自动计算。直接选择完整表面或观测深度图时同步切换送测版本。其余预览沿用送测选择，距离摘要明确标注来源。

生成页与分析页通过实例ID同步所选目标。默认只标注该目标的端点连线与 `L = ... mm`；图像上的长度、表格、摘要、点云顶部与导出均使用核心计算结果 `distance_m`。端点拒绝、缺失或尚未计算时不给出有效长度。伪深度结果始终注明人工尺度和伪深度来源。

每次输入或测距参数变化都会使旧结果失效。工作线程计算输入快照，仅接收当前输入版本的结果；忙碌时只保存最新待处理输入。人工编辑未应用时，旧距离隐藏并禁用结果导出。取消排队测距后保留最新成功生成的输入供手动重算。新图片加载失败时恢复上次成功来源，同时保留失败提示；未应用编辑仍需处理。

两个工作页保留编辑、缩放、选择、图表状态。小窗口下点云设置默认折叠，点击“点云设置”可展开全部原有控件；图表说明可悬停标签查看。常用1366×768、1920×1080窗口已纳入原生Qt检查。

关闭窗口时统一取消生成与测距任务，等待线程退出。保留 `PseudoDepthDialog` 兼容包装供旧独立工具使用，工作台本身使用嵌入式 `PseudoDepthPanel`。

验证入口：`python -m unittest discover -s tests`；原生Qt样例检查：`python work/check_unified_workspace.py`。后者使用已有两张改进样例中的第一张，不重新下载模型或更改测距阈值。截图与导出核对报告位于 `outputs/unified_workspace_review`。没有进行实机精度验证。

## 点云细节导航

- 滚轮缩放0.05–80倍，每格8%，约110ms平滑过渡；反向滚轮立即按当前画面反向，不继续追旧目标。每个动画帧都保持鼠标位置锚定；Shift+滚轮按正常速度的1/5精调。水平滚轮或空滚轮不改变视图。
- 单击点云取得键盘焦点后，W上、S下、A左、D右平移画面；按住连续移动，Shift减速至1/5。松键、失去焦点、隐藏页面或切换输入立即停止，文字输入框中的WASD不影响点云。按键平移或鼠标开始拖动会停止未完成的缩放动画，防止相互干扰。
- 单击样本后按F或点击“聚焦样本 F”，样本居中并成为旋转支点。支点只属于观察相机，端点参考、样本XYZ及长度不改变。聚焦放大程度按邻近最多120个可见类别样本的投影范围确定，不删除其余点。
- “返回端点”以原端点为观察中心并保留缩放；“适配点云”适配当前显示范围与类别；“复位视角”、Home或双击恢复默认观察状态。
- 适配只根据点云，不让坐标轴、端点标记及相机箭头压缩显示比例。按用户要求恢复原坐标轴与透明网格：固定轴长为搜索半径的0.62倍，原有毫米标签、七线网格及朝相机箭头保持原样；聚焦远离端点时，原坐标原点可能在画外。
- 点击“展开点云”在当前分析页内扩大画布，不另开窗口；Esc或“收起点云”恢复布局。使用同一画布，保留旋转、缩放、支点、选点及米制数据。
- 放大显示现有深度样本，不通过插值制造额外深度。原生鼠标选点、F、连续滚轮、360°旋转和布局收起检查入口为 `python work/check_cloud_detail.py`，截图与检查报告位于 `outputs/cloud_detail_review`。

缩放数字以当前适配视图为1×，不是相机距离倍率或固定毫米比例尺。真实等比模式下XYZ共用一个显示系数；同一视深度处X/Y屏幕尺度相同，透视模式下不同视深度的像素/毫米本来不同。倍率改变只调整观察画面，不改变样本XYZ、端点参考及测量长度。Z夸张模式仍明确标为非等比。

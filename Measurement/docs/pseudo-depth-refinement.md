# 2026-10-26 深度模拟改进

运行 `D:\318\python.exe -m icicle_measure --pseudo-depth`。选择 `002_00002` 或 `002_00041` 时优先加载 `outputs/pseudo_depth_refined` 中的新样例；其余四张保留原版本。桌面快捷方式不需要修改，已经打开的旧程序需重新打开才会加载新代码。

## 本轮改动

- 近端饱和的模型目标不再自动使用被截断的0.5m作基线，而是明确使用1.25m默认假设；可人工设置。
- 只有稳健线性拟合残差≤15mm、首尾变化≤100mm且有未饱和前景支持，才保留模型轴向趋势。否则零倾斜是假设，显示在诊断中。横截面仍按可见掩膜宽度构造。
- 分割候选用原图边界作弱排序依据；不允许候选违反人工正负提示。透明物体边缘仍有歧义，分割不是实测真值。
- 新增圈选背景平面工具：按多边形顺序点选，输入区域包围框左上/右上/左下三个深度，再确认。采用 `1/Z=a*u+b*v+c`，因此反投影得到平面；不是直接对Z线性插值。对象掩膜、无效区域不参与替换。
- 背景改动不改变冰凌表面候选；原始模型映射单独可看。平面参数、人工分割提示、忽略目标、重叠归属均保存在项目里，可重现。
- 可忽略重复检测（保留原检测记录）或人工指定重叠像素归属；掩膜可恢复。未确认的重叠继续标为无效，不为提高通过率自动认领。
- 旧项目没有 `generation_version` 字段时按旧算法重载；应用新修正会使用新版，旧目录未被覆盖。

## 两张对照样例

执行 `D:\318\python.exe -m icicle_measure.pseudo_refine_review` 可复现。输出 `outputs/pseudo_depth_refined/review.html`。

样例墙面分区经人工查看RGB指定，不是自动识别。墙角分区分别设置深度锚值，保护插座、支架等轮廓；这些保护区域保留原模型，仍可能有错误。冰凌基线人工设为1.25m，长度先验完全不参与拟合。样例包含原RGB、掩膜、旧版、新版表面、人工墙面约束、独立观测缺陷以及等比例相机点云对比。

第二张额外的9/10/11号候选经图像查看作为重复候选忽略，检测记录保留；并未把所有重叠都当重复。剩余粘连和遮挡处继续标注待修，不能据此宣称完整自动恢复。

输出仍是人工尺度的伪深度，D435i约定仅指Z16格式与比例换算。测距算法、拒绝阈值及点云几何没有修改。

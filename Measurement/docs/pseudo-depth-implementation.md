# 场景伪深度实施记录

已批准方案：Depth Anything V2 Small 全图相对深度、MobileSAM 逐框掩膜、连续假想冰凌表面、D435i Z16 对齐后格式；1280×720 等比留边；完整与带误差两份输出。距离先验 0.5–2 m，长度常见 18–22 cm、极限参考 17–25 cm，非标定真值。

实施顺序：

1. 固定官方代码与权重，建立共享 CPU PyTorch 的独立可选环境。
2. 实现坐标变换、模型缓存、表面构建、可重复观测缺陷与 Z16 编解码。
3. 保存带来源、假设内参、人工修改的可重载项目及输入清单。
4. 接入 PyQt 工作线程、掩膜/背景修正、深度比较和现有测距流程。
5. 六张真实 RGB 样例及格式、数据流、GUI、回归验收；报告实测耗时。

批量 400 张须待用户查看并确认六张样例后开放。生成过程不得调整测距门槛以追求通过。

已完成上述步骤。六张真实 RGB 样例及两种 Z16 输入保存在 `outputs/pseudo_depth_samples`；样例验证、真实提示点重分割/子进程取消探查、长度先验更新记录分别为 `validation_report.json`、`interaction_probe.json`、`length_prior_update.json`。当前 61 项单元测试通过，包括 1366×768 窗口与跨实例参数保留。六张共 53 个实例，最终观测测距通过 10 个；这不是精度通过率，未改变判定门槛。长度先验扩展后的两份深度逐像素保持一致。

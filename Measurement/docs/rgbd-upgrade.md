# 点云与真实输入升级（2026-10-26）

## 启动与查看

原启动方式不变。点云默认首选、诊断标签仍可拖动换位。点云改为深色画布，修复颜色分组破坏前后遮挡的问题，增加毫米轴长度、按投影密度调整点大小、类别显隐、像素联动和独立大图。

- “搜索窗全部点”保留前后景。真实 Z 间距大时，目标横向宽度会显得很小。
- “像素圆邻域”按原图半径筛选，不会按 Z 排掉背景。
- “三维球邻域”按真实 XYZ 距离筛选，可能隐藏远背景；空范围不补入其它点。
- 左拖旋转、右拖平移、滚轮缩放、双击复位。“视角与坐标轴”展开转向按钮、固定观察方向和轴显隐。“适配点云”保持当前方向重新适配。
- 单击样本查看原像素、Z、绝对及相对 XYZ，主图同步标出该像素。“独立大图”保留打开时的数据，不随主工作台切换目标。
- XYZ 统一等比缩放，类别不改变坐标。Z×4 为明确标记的非等比观察模式，不参与测距。候选原点始终保留未验证标记。
- 超过 10000 点时仅显示抽样，算法仍使用全部有效样本。

## 离线真实深度

支持单通道 16 位以上整数或浮点 NPY、PNG、TIFF，拒绝 8 位预览、彩色深度和 JPEG。原 m/mm 输入保持兼容。设备原始值使用以下字段替代 m/mm：

```json
{"depth_unit": "raw", "depth_scale_m_per_unit": 0.00025}
```

比例必须来自设备或数据集，上例不能代替实际标定。它表示一个原始单位对应多少米；与 m/mm 同时指定会被拒绝，避免重复换算。可增加 `intrinsics_image_size: [宽, 高]` 核对内参分辨率。离线输入仍须提前对齐、去畸变；声明与尺寸相同无法证明配准正确。

导入后显示有效深度比例。低覆盖率提示检查数据，端点是否可测仍由已有规则决定。零、NaN、Inf 和范围外数值不参与计算，不自动补洞、不使用模拟深度兜底。结果增加 source 来源信息。

## D435i 和 YOLO11

本机现有 Python 3.9 已安装并验证可导入 `pyrealsense2==2.56.5.9235`；设备枚举为 0。其他机器安装可选组件：

```powershell
D:\318\python.exe -m pip install --only-binary=:all: -r requirements-camera-py39.txt
```

点击“D435i 相机”。采集线程默认 640×480、30 FPS，读取设备比例，将深度对齐彩色图，再使用同一去畸变映射。RGB 线性插值，Z 最近邻，不混合前后景深度。支持无畸变和 Brown-Conrady 类型，其他非零畸变模型拒绝。没有设备或 SDK 时显示可读原因，离线功能仍可用。

默认选择项目内 `training/pose_2kpt/runs/yolo11n_pose_78_2kpt/weights/best.pt`，也可手动选择 `[2,3]` 两点 Pose 权重。框和关键点按同一实例索引绑定。默认点序为尖端、根部，可在采集窗反转；两类置信度分别设置，低置信度点作为缺失点处理。

抓拍将完整 RGB-D 帧冻结后检测、测距。持续模式在计算空闲后取最新帧；邮箱只保留最新一帧，不积压推理任务，不承诺每帧推理或跨帧目标跟踪。预览在采集窗，工作台显示与结果对应的冻结帧，保存帧号、采集及完成时间和模型参数。“取消”同时暂停持续测量。

“保存当前 RGB-D”保存冻结 RGB、米制深度、检测及来源元数据，可再次导入。来源比例保留作审计；保存深度已经是米，再导入不会二次缩放。

## 排错与验收

修复点云遮挡顺序、缺失尖端时根部的标注颜色、极端框导致的绘图错误及过期图表测试断言；空间连通分量改为仅在搜索区域分配掩膜，减少大图开销。

本轮已完成 34 项单元测试、24 项点云几何检查、61 项压力检查。新增检查包括原始比例、异常格式、去畸变边界、SDK 对齐调用、帧绑定、邮箱丢旧帧、停止及异常恢复、实例关联、点云遮挡和导出一致性。真实 YOLO11 在一张真实 RGB 上检出 1 个实例并进入测距；配套深度为构造的单平面，结果正确拒绝输出长度。1 万点离屏绘图中位约 30 ms、95 分位约 42 ms，仅表示本机模拟渲染性能。

```powershell
python -m unittest discover -s tests -v
python -m icicle_measure.test_pointcloud_geometry
python -m icicle_measure.stress_test
```

当前没有相机或真实深度样例。已验收的是软件流程与模拟几何，D435i 现场连接、配准质量及透明冰凌的真实误差尚待设备和已知长度目标检验。统计分簇不能恢复未被传感器观测到的真实冰凌深度。

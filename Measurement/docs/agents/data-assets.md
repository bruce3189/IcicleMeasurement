## 4. 标签格式

### 4.1 YOLO Pose（YOLO 训练实际读取）

**三点版（14 字段）**：

```
0 cx cy w h  x1 y1 v1  x2 y2 v2  x3 y3 v3
└class       tip        base_left  base_right
```

**两点版（11 字段）**：

```
0 cx cy w h  x1 y1 v1  x2 y2 v2
             tip        base
```

全部归一化到 0–1。`v` 取值：`2` 可见已标 / `1` 遮挡 / `0` 缺失未标 —— **`v=0` 时前两个坐标不是有效坐标，必须按缺失处理，不能当 (0,0) 参与计算**。

两点版里 `base = (base_left + base_right) / 2`；`base` 的可见性只有两个原点都可见时才为 2。

### 4.2 labelme JSON（人工标注源）

```json
{"label":"ice",  "points":[[780.82,1155.29],[853.77,1636.47]], "shape_type":"rectangle"}
{"label":"tip",  "points":[[835.73,1622.29]],                  "shape_type":"point"}
```

- 矩形 `label=ice`，点 `label=tip / base_left / base_right`
- 三点靠 `group_id` 与所属框绑定（待标副本里每图从 1 开始）
- 坐标是**绝对像素**，不是归一化值

### 4.3 `data.yaml` 对照

| 数据集 | 文件 | `kpt_shape` | `flip_idx` | `kpt_names` |
|---|---|---|---|---|
| 两点检测_78 | `dataset.yaml` | **[2, 3]** | **[0, 1]** | `[tip, base]` |
| 根根分明 | `dataset_全80张.yaml` | [3, 3] | [0, 2, 1] | 无 |
| 根根分明 | `dataset_核心31张.yaml` | [3, 3] | [0, 2, 1] | 无 |
| 数据集_400 | `dataset.yaml` | [3, 3] | [0, 2, 1] | `[tip, base_left, base_right]` |
| 训练集_232 | `dataset.yaml` | [3, 3] | [0, 2, 1] | `[tip, base_left, base_right]` |

`flip_idx [0,2,1]` 表示水平翻转时 tip 不动、左右 base 互换。**正因如此，训练时必须关掉翻转增强**（`fliplr=0`），否则关键点语义会被破坏。

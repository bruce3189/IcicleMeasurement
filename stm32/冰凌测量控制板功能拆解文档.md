# 冰凌测量控制板（STM32 下位机）— 功能拆解文档

> 2026-10-27 精简版。功能范围以《冰凌测量控制板需求与现状清单.md》为准；本文件只定义模块职责和配合方式。2026-10-28 已增加 `firmware/` HAL 模块框架；串口协议和 OLED 控制器驱动尚待接入，未做实物验收，不写“全部驱动已完成”。

## 一、系统边界与模块

树莓派负责 D435i 采集、识别和测距。STM32 负责按键、串口、显示与照明控制。最小系统板的电源、晶振、复位、启动配置和 SWD 属于平台，需按实物检查，不重复计成自研外围模块。

本版从原 8 个硬件模块减为 5 个，保留旧编号以便对照。模块编号不是实现顺序；没有串口工具时可以先点亮 OLED。

| 模块 | 职责 | 对应需求 |
| --- | --- | --- |
| 模块1：USART1 | 与 PC 或树莓派双向通信、解析有效帧、检测失联 | R7、R8、R10、R11 |
| 模块2：OLED | 显示通信状态、测量状态、结果或失败提示 | R6 |
| 模块4：双状态 LED | 绿灯正常，红灯故障/失联 | R4 |
| 模块6：两键 | START 发请求；STOP 发请求并在本地关灯 | R1、R13 |
| 模块7：照明驱动 | 执行手动占空比设置，默认关闭 | R2 |

模块3（光敏自动调光）、模块5（蜂鸣器）和模块8（硬复位树莓派）从本版移除，不继续分配引脚或保留软件任务。

## 二、各模块职责与验证

### 模块1：UART 通信

- 使用 USART1，115200 8N1，3.3V 信号。验证阶段接 USB-TTL/PC，最终接树莓派，同一时刻只连接一个外部发送端。
- 收发 START/STOP 请求、状态、结果、`LIGHT_SET(percent)`、故障、心跳和回执；参数和完整帧封装统一后再分别实现两端。
- Pi 每 500 ms 发心跳；STM32 回执。MCU 端超过 3 s 没收到有效心跳，执行本地关灯和失联提示；上位机也应检测回执是否超时。
- 只有完整且校验通过的命令才能修改状态或占空比。OLED 刷新和按键处理不能使接收遗漏；具体驱动实现不在本文规定。
- 验证：外部设备按 115200 8N1 实际收发；正常帧、错误帧、半帧、断线与重连分别测试。自环不能代替外部时钟和连线验证。

### 模块2：OLED

- 使用现有 0.96 英寸 128×64 I²C 屏；控制器和地址在实物确认后选择驱动，不能靠尺寸或画面偏移唯一判型。
- 固定显示三类信息：`LINK OK/LOST`、`STATE READY/MEASURING/STOPPED/FAULT`、`L=xxx.x mm` 或 `NO RESULT`。
- START 按下后先等待上位机确认，不能自行宣布测量开始；只有上位机返回有效距离才显示数值。
- 新测量、取消、拒绝、故障或失联时不把旧距离当作当前结果。需要诊断时可临时显示测试计数，不增设长期调试菜单。
- 验证：固定文字和边框正常；上位机模拟状态和结果能显示；收到拒绝/取消状态后数值区域正确清除。

### 模块4：状态 LED

- 使用绿、红各一颗 LED，各自串限流电阻。无需设计多种闪烁编码。
- 连接正常且无故障：绿亮红灭；未连接、失联或收到故障：红亮绿灭。
- 验证：两颗灯分别可控，再验证它们与 OLED 的状态含义一致。

### 模块6：START / STOP 两键

- 保留两个独立按键，按下为低电平。软件做防抖，一次按下只产生一次请求，不识别长按与组合键。
- START：仅在连接正常且上位机允许开始的状态下发送请求；实际开始由上位机确认。
- STOP：立即将本地占空比清零、取消尚未执行的开灯操作，并向上位机发送停止请求。
- STOP 是操作停止，不是安全等级急停，不增加第三个 ESTOP 键。
- 验证：一次按下只计一次；失联时 START 不启动任务；STOP 不等待串口应答即可关灯。

### 模块7：手动照明控制

- 由上位机命令或 PC 演示脚本指定 0–100% 占空比；两颗操作键不承担亮度调节，不增设旋钮或自动调光。
- 使用白光 LED 小负载与逻辑电平 MOSFET。小 LED 组只验证开关和调光，不承诺满足最终拍摄照度。
- 上电、复位、STOP、故障和失联时关灯；恢复通信后等新的有效命令，不恢复旧占空比。解除故障并同步状态后才接受重新开灯。
- 面包板可先用 1 kHz 验证 PWM。用于成像前，先以 100% 常亮建立基线，再在实际曝光与帧率下检查 PWM 条纹、亮度变化和深度有效率。
- 验证：0%、50%、100% 可区分，测量电流符合 LED 额定值，所有本地停止条件均能关灯。

## 三、最小数据流

```text
START / STOP 两键 ──→ STM32 ──USART1──→ PC模拟端 / 树莓派
                       ↑                  │
                       └────状态/结果/心跳/亮度────┘
                       │
                       ├─→ OLED：状态与结果
                       ├─→ 绿/红 LED：正常与故障
                       └─→ PWM + MOSFET：白光照明

D435i ──USB──→ 树莓派：图像处理与测距，数据不经过 STM32
```

失联处理只保留一层：3 s 超时后关灯并提示。没有 10 s 复位、Flash 日志、温度采集或自动亮度状态机。

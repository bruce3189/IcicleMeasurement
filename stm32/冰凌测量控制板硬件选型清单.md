# 冰凌测量控制板 — 硬件选型清单

> 2026-10-27 精简版。对应本版 5 个硬件模块：1 通信、2 OLED、4 双 LED、6 两键、7 手动照明。先搭面包板，PCB 继续采用插接式最小系统板。

## 一、第一版必需物料

| 物料 | 数量 | 规格与用途 |
| --- | --- | --- |
| STM32 最小系统板 | 1 | STM32F103C8T6；核对实物供电、排针和尺寸，不能只按通用网图画封装 |
| ST-Link | 1 | SWD 下载调试；供电/电压参考引脚按具体型号说明接线 |
| 面包板、杜邦线 | 1套 | 按已确认的电源路径搭建，所有信号共地 |
| 5V 电源及合适的 USB 线 | 1套 | 面包板阶段只保留一个控制板供电来源 |
| OLED | 1 | 现有 0.96 英寸、128×64、I²C；核对控制器、供电电压、上拉和地址 |
| 状态 LED | 2 | 绿/红各一颗 |
| 轻触按键 | 2 | START、STOP；6×6 mm 按键的同侧引脚可能内部相连，先确认接点 |
| 白光 LED | 3 | 低功率演示用，每颗单独限流；最终照明另按成像测试选型 |
| 220Ω 电阻 | 5 | 状态 LED ×2、白光 LED ×3；按实际正向压降核算电流 |
| AO3400A N沟道 MOSFET | 1 | 照明低边驱动；SOT23 裸件不能直接插面包板，需已焊好的 SOT23 转 DIP 转接板 |
| 470Ω 电阻 | 1 | PWM 引脚至 MOSFET 栅极串联 |
| 100kΩ 电阻 | 1 | MOSFET 栅源下拉，接在栅极与源极之间 |
| USB-TTL | 1，外部通信联调时需要 | 实际 TX/RX 电平为 3.3V；不能仅根据模块电源跳帽认定信号电平 |
| 万用表 | 1 | 查短路、测电源和 LED 电流；测 PWM 频率/占空比需示波器或逻辑分析仪 |

没有 USB-TTL 时可以先完成点灯、OLED、按键和照明，并做 UART 自环；但还不能声称外部 UART 已验收。

## 二、照明驱动的选择

本版统一采用 AO3400A，不再同时列“S8050 或任意小 MOS”两套未核算的接法。厂家给出了 `VGS=2.5V` 时的导通电阻规格，适合本版 3.3V 控制的小负载；不能把栅极阈值电压当作充分导通的依据。[AOS 官方参数](https://www.aosmd.com/products/mosfets/low-voltage-mosfets-12v-30v/ao3400a)

5V 输入下，每颗白光 LED 串 220Ω，若正向压降约 3V，则单路约 `(5−3)/220≈9mA`，三路约 27mA。该数值只是估算；最终应根据实际 LED 数据表和测量值确认，不能把“总电流小于100mA”当成单颗 LED 不会过流的保证。

正式光源若不是这组三颗低功率 LED，应重新核算供电、驱动和散热，不直接复用本版参数。

## 三、现有但本版不用的物料

光敏电阻模块、第三颗操作按键、蜂鸣器及其 S8050 驱动、硬复位拨码开关、RUN 串联电阻均不列入本版必需物料。已有实物可留存，不新增 ADC、蜂鸣或复位功能来消耗库存。

不采购温度传感器、WiFi 显示附件、电池管理板或第二路调试串口模块。

## 四、供电与采购确认

- OLED 和控制信号按 3.3V 设计，核对模块上拉没有接到 5V；与 Pi 相连的 UART 必须是 3.3V 电平。
- 控制板用单一 5V 来源，3.3V 由核心板 LDO 提供；先确认其能承担核心板、OLED 和状态 LED 的实际负载。
- USB-TTL 默认只接 TX/RX/GND，不接其 5V 或 3.3V 输出；树莓派独立供电，本版不从其 40 针接口给控制板供电。
- 原装 ST-Link 的目标电压参考输入与常见小棒的 3.3V 电源输出不同，不能把所有“3.3V”端子按同一种方式处理，详见接线文档。
- `JMD0.96D-1` 丝印、0.96 英寸尺寸或 I²C 地址不能单独证明 OLED 控制器型号；优先查商品资料和模块原理图，再按实物验证。

## 五、转为 PCB 时增加的物料

1. 与实物核心板匹配的两排排母；确认排距、脚距、线序、插入方向和下方元件净空，不按“所有蓝板都相同”处理。
2. OLED、双按键、LED 与外部照明所需的连接器或板载封装。
3. 按最终电源来源选择输入连接器与相应保护器件，不再额外并联一套 3.3V 稳压器。

不为已删除的光敏、蜂鸣器、第三按键或树莓派复位功能继续预留整套器件与接口。

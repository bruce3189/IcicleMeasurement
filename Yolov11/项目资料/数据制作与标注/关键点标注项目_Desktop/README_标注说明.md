# 冰凌框与关键点标注（Labelme + YOLO Pose）

数据共 400 张，按来源视频分组：001/002/003 为 train（201 张），004 为 val（94 张），005 为 test（105 张）。

## 标注规则

- 每根冰凌单独标一个矩形框。
- 一个完整实例由一个框和同一 `group_id` 下的三个点组成，顺序固定为 `tip`（冰凌尖端）、`base_left`（底面左角）、`base_right`（底面右角）。
- 三个关键点都能在冰凌本体上确认时，标为 `完整入镜`；贴近图像边缘本身不代表不完整。
- `部分可见` 必须同时满足：冰凌被图像边缘裁切，且无法确认三个关键点中的一个或多个。图像内部的遮挡或关键点缺失不能单独标为此类。
- 多根冰凌对应的矩形框在局部明显挤在一起、相互重叠时，仍逐根标框，相关实例标为 `严重重叠`；边缘裁切但不属于重叠簇的实例按“部分可见”规则判断。能确认三个关键点的严重重叠实例仍保留三个点。
- 关键点应落在冰凌本体轮廓上，不是矩形框角。近似点应对照原图微调。

## 在 Labelme 中编辑

打开 `images` 文件夹；每张图使用同基名 JSON，例如 `001_00001.jpg` 对应 `001_00001.json`。框和该冰凌的三个点使用相同 `group_id`。修改框类别时，从 `完整入镜`、`部分可见`、`严重重叠` 中选择。

## 输出格式

- `images/`：原图及 Labelme JSON。
- `labels/`：Ultralytics YOLO Pose `.txt`，每个目标一行，依次为类别、归一化框、`tip/base_left/base_right` 的归一化坐标与可见性。
- 无法确认的关键点以 visibility `0` 输出；可见点以 visibility `2` 输出。
- `splits/`：按视频分组的 train/val/test 清单。
- `dataset.yaml`：训练配置；运行 `labelme_to_yolo_pose.py` 可按 JSON 重建 YOLO Pose 标签。
